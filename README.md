# Zachary Baker - Grapple Challenge

What I have:
3D speedrun platformer utilizing a grappling hook.

Move with WASD

Jump with Space

Grapple mechanics:

I couldn't figure out how to use the Unreal Physics Restraint alongside Character Movement... so I just implemented the grappling physics myself!!

Left click - Shoot out a grappling hook. If it lands on a rusty spot, it can grapple!

E - Reel in grappling hook.

Right click - Pull yourself towards the hook. If you are already towards the hook, it performs a grapple jump.

By combining the reel and the pull, you have a lot of fine control over where you go. You can perform a lot of fast maneuvers.

Try to get the best time!




Features:
A main menu,

-Five individual challenges making up the challenge level. Each one attempts to test different abilities with the hook.

-Music and sound effects

-Game timer that keeps track of your best score.
